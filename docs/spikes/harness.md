# Harness spikes (milestone 3)

Run on 2026-10-09 with Claude Code 2.1.291, in a live interactive session (a hot-reloaded spike mod logging every event it saw) and in a `claude -p` session with code-kit's hooks.

| #   | Assumption                                                           | Result                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| --- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A   | A mod can tell the lead is idle and prompt it                        | **Holds.** On `turn.complete` the mod's `$.prompt.submit` started the next turn within a second, marked with the plugin as its origin. A prompt can't be submitted from a `command.run` hook (it would wait on the turn that hook holds); submit from `turn.complete`.                                                                                                                                                                                                                                                                                                   |
| B   | A mod can hold a call the hooks refuse and let the same call through | **Holds, by retrying.** `next(e)` returned code-kit's refusal (the PreToolUse hook's text, as an error result); the mod wrote the approval and called `next(e)` again; the install ran and the agent got the normal result. No pre-check needed: the mod reads the refusal (as the refusal cards already do) and retries. Mods also run under `claude -p` (`isInteractive: false`), without drawing.                                                                                                                                                                     |
| C   | Background agents run beside the lead, their usage measurable        | **Holds through the lead; a mod can't start one itself in auto mode.** `$.agent.spawn` from the mod was refused twice by auto mode's classifier ("the request that produced this action did not ask for one"), even after the person typed a command; the Agent tool can't be called through `$.tool.call` either. Prompting the lead to start the agent worked: the lead's Agent call went through, and the agent's report started a new lead turn by itself. Usage is attributed per agent: `turn.step` and `turn.complete` carry `agentId`, the model and the tokens. |
| D   | Each agent's last activity is visible                                | **Holds.** Every `tool.call` from a subagent carries its `agentId`; the lead's carry none.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| E   | Cell graphics and live regions draw in the person's VS Code terminal | **Open:** the probe pane.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

## What changes in the design

- **No judge refactor.** Hold and ask (06) lets the hooks refuse, recognises a refusal that a person's approval would allow from its text, asks, writes the approval and retries the same call. ST-12 becomes "Reading refusals for hold".
- **Background agents are started by the lead.** The reviewer (07), and Context Graph's card writer and curator, are started by prompting the lead ("start a background reviewer for web/st-4 with this brief"), not by the mod; the mod watches them by `agentId` and reads their results from the turn their report starts.
- **Prompts come from `turn.complete`**, never from a command's own hook.
